# 複製網址書籤

使用某些瀏覽器複製網址時，中文會以這個樣貌呈現：「%e6%9b%b8%e7%b1%a4」。

複製給別人時就會很麻煩。

遇到這個情況，只要點擊這個書籤，就能複製到比較直觀的網址。

另外，在某些網站複製網址時，會添加追蹤參數，讓網址轉寄給別人時，變很長一串，複製給別人時也會很麻煩。

所以也添加了第二個書籤，在複製網址時可以去除已支援的追蹤參數。

網址：https://birdeggb2777.github.io/forme/網頁程式/瀏覽器書籤/複製網址書籤/複製網址書籤.html
